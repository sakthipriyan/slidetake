Privacy & analytics

Your decks, copies and recordings never leave this browser. This is only about counting visits to slidetake.com.

slidetake:analytics in this browser remembers your choice. Everything else is on the privacy page.

Start a new deck

Pick a template. It opens as it is; start typing and it becomes your own copy at /edit.

  • BlankA first card, a section and a detail.
  • TalkWhy it matters, the idea, trade-offs, summary.
  • RecordingCamera steps, an overview moment and a closing on camera.
  • ShowcaseEvery feature in one deck: diagrams, charts, images, YouTube, camera.

Or ⇣ Load a deck from a link, or Open a file from this computer.

Load a deck from a link

Paste a link to a markdown file: a GitHub file or folder, a gist, or any URL that allows other sites to read it.

Short links

slidetake.com/gh/owner/repo/path/deck.md opens a file on GitHub (add @branch after the repo for another branch), and slidetake.com/gist/<id> a gist. Images next to the deck load as they are.
